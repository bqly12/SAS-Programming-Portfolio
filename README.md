# SAS-Programming-Portfolio

## Overview
This repository serves as a collection of SAS programming projects completed during my undergraduate coursework. The scripts demonstrate a range of statistical and programming skills from financial stimulations to biostatistical health analysis.

## Project Descriptions

### 1. Finance Stimulation Loops
* **Context**: Statistical programming focused on financial forecasting and stochastic simulation.
* **Key Skills**: Implemented iterative logic using `DO` Loops and conditional `UNTIL` processing to project multi-year cost-benefit scenarios. Utilized ***Arrays*** to efficiently process vector data for discount applications across multiple months. Generated synthetic datasets using `RAND` and visualized fits using `PROC SGPLOT` histogram and density curves.

### 2. Sleep Apnea Analysis
* **Context**: Independent analysis of a small health dataset from a machine learning repository.
* **Key Skills**: Performed data wrangling to create categorical bins and dummy variables. Conducted ***One-Way ANOVA*** and ***ANCOVA*** to model Apnea Hypopnea Index (AHI) trends, controlling for oxygen saturation. Used `PROC GLM` for interaction testing and Tukey's post hoc analysis, and validated model assumptions using `PROC REG` residual diagnostics. 

### 3. Model Selection Techniques
* **Context**: Comparative analysis of prostate cancer dataset to identify key biological predictors.
* **Key Skills**: Implemented automated variable selection algorithms (***Forward, Backward, Stepwise***) using `PROC REG` to build multivariate regression models. Optimized model performance by evaluating competing criteria including ***Mallow's Cp, AIC, BIC, and Adjusted R-Square***. Utilized `OUTEST` datasets and sorting procedures to identify the best model.

### 4. Biostatistical Factor Studies
* **Context**: Analysis of experimental design data focusing on single-factor and two-factor biological treatments.
* **Key Skills**: Applied ***General Linear Models (`PROC GLM`)*** to analyze variance in Factorial Designs. Evaluated ***Interaction Effects*** between treatment groups to determine the appropriateness of Main Effects testing. Conducted post-hoc multiple comparisons using ***Tukey’s HSD*** and ***Scheffe’s method***, and formulated null/alternative hypotheses for both Cell Means and Treatment Effects models.
